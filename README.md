# Boombox — бумбокс с музыкой для Paper 1.21.1

Ставишь на пол модель бумбокса, ПКМ — меню с треками, музыка играет всем, кто рядом.
Модель и музыка едут через **ресурспак** (работает на обычном клиенте, без модов). Плагин сам собирает пак из твоих `.ogg`/`.mp3` и сам раздаёт его игрокам.

## 1. Сборка

Нужен JDK 21 и Maven:

```
mvn clean package
```

Готовый файл: `target/Boombox-1.0.0.jar`.

Без установки Java/Maven: залей эту папку в свой репозиторий на GitHub → вкладка **Actions** → запуск `build` → скачай артефакт **Boombox** (внутри jar).

## 2. Установка

1. Нужен **Paper 1.21.1** (или форк: Purpur, Pufferfish) и Java 21.
2. Положи jar в `plugins/` того Paper-сервера, где будут стоять бумбоксы. На Velocity-прокси ставить не нужно.
3. Запусти сервер один раз — появится `plugins/Boombox/config.yml`.
4. Укажи, откуда игроки скачают ресурспак (см. раздел 3), потом `/boombox reload`.

## 3. Раздача ресурспака (важно!)

Без ресурспака игроки не увидят модель и не услышат музыку.

**Вариант А — плагин раздаёт сам (по умолчанию).**
Плагин поднимает маленький HTTP-сервер на порту `8123`. Нужно:
- открыть этот порт на машине с Paper (файрвол / панель хостинга);
- вписать публичный адрес в конфиг: `resource-pack.server.public-url: "http://ТВОЙ_IP:8123"`.

**Вариант Б — если порт открыть нельзя** (на многих хостингах так).
Файл `plugins/Boombox/pack/boombox-pack.zip` залей на любой хостинг с **прямой** ссылкой и впиши её в `resource-pack.external-url`. Встроенный сервер тогда не используется. После каждого добавления/удаления трека zip нужно перезалить.

Пак отправляется при входе игрока и заново — когда набор треков изменился. Музыка включается только тем, у кого пак уже загрузился.

## 4. Музыка

- Minecraft играет только **Ogg Vorbis** (`.ogg`).
- Положи файлы в `plugins/Boombox/music/` и сделай `/boombox reload`, **или** загрузи по прямой ссылке: `/boombox add <ссылка> [название]`.
- `mp3 / wav / flac / m4a ...` плагин конвертирует в `.ogg` сам, если на машине установлен **ffmpeg** (оригиналы переносятся в `music/_originals`). Без ffmpeg клади готовые `.ogg`. Вручную: `ffmpeg -i in.mp3 -ac 1 -c:a libvorbis -q:a 4 out.ogg`.
- Делай треки **моно**: тогда звук затухает с расстоянием. Стерео играет с постоянной громкостью (в пределах радиуса).
- Любое изменение набора треков = новая версия пака, игроки перекачивают его целиком. Держи треки небольшими (моно, q4 — около 1 МБ на минуту).

## 5. Как пользоваться

| Действие | Как |
|---|---|
| Получить бумбокс | `/boombox give [игрок]` |
| Поставить | взять в основную руку, ПКМ по **верхней грани** блока |
| Меню музыки | ПКМ по бумбоксу (право `boombox.use`) |
| Забрать | Shift+ПКМ по бумбоксу (владелец или админ) или кнопка в меню |

В меню: выбор трека, **Стоп**, громкость ±10 % (трек перезапускается), режим **повтора** (выкл / один трек / весь список по кругу), «Забрать бумбокс».

**Чтобы бумбокс играл всегда** (например, на спавне): выбери трек и режим «весь список». Музыка продолжится после рестарта сервера и после выгрузки чанка, пока не нажмёшь «Стоп».

Музыку слышат игроки в радиусе `music.radius` (24 блока). Отошёл — звук выключается, вернулся — трек начинается с начала (перемотать клиент нельзя).

## 6. Своя модель

Всё, что лежит в `plugins/Boombox/pack-extra/`, копируется в пак поверх стандартного. Положи туда свою модель из Blockbench с теми же путями:

```
pack-extra/assets/boombox/models/item/boombox.json
pack-extra/assets/boombox/textures/item/<твои текстуры>.png
```

Требования к модели: низ на уровне y=0, центр по X/Z в точке 8 (как на сетке Blockbench), «перед» — сторона north. Стоит задом — поставь `model.yaw-offset: 180`. Размер — `model.scale`, область клика — `model.hitbox-width / hitbox-height`.

Модель привязана к предмету `item.material` (по умолчанию `PAPER`) через `custom-model-data`. Если другой ресурспак на сервере уже переопределяет модель этого предмета, поменяй материал на редкий.

## 7. Команды и права

| Команда | Право |
|---|---|
| `/boombox list` — список треков, `/boombox pack` — получить пак ещё раз | — |
| `/boombox give [игрок]`, `/boombox reload` | `boombox.admin` |
| `/boombox add <ссылка> [название]`, `/boombox remove <id>` | `boombox.upload` (по умолчанию op) |

Права: `boombox.use` (меню, по умолчанию все), `boombox.place` (ставить, по умолчанию все), `boombox.upload`, `boombox.admin`. Чтобы меню управляло только избранным, заберите `boombox.use` у группы игроков через ваш плагин прав.

Все тексты и настройки — в `config.yml`.

## 8. Статус проверки

Логика плагина (сканирование и конвертация треков, сборка и раздача пака, цикл воспроизведения, повтор, возобновление после рестарта) проверена тестами на заглушках API. На живом Paper 1.21.1 плагин не запускался: если при сборке или запуске что-то не так — пришли лог.
